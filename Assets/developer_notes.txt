------------------------
SUMMARY
------------------------
A 3d puzzle-platformer-collectathon game with a grapple hook
central mechanic.  Attacks are technically possible, but not
emphasized, and combat is not difficult

- Decomplexify the camera controller so it doesn't have 2
follow objects.  Make it lerp to a target position rather
than set its transform position.  This will reduce camera
jitter.   Give the camera the option to be first person or 
third person, and create more complex camera animation 
effects for cinematic moments in gameplay. A main goal should 
be to make the camera code modular and reusable for future 
games I build

- Refactor and simplify character movement scripts.  Should
account for moving platforms, slippery surfaces(?), and
multiple movement modes (running, water skating, etc.).
Create a setting for allowing movement midair vs. not for
gameplay testing.

- Make level loading more seamless by either having a large
level that disables objects not in a bounding box, or by
having asynchronous multi-level loading enabled

- Saving / loading.  Currently uses a tree structure that
should be refactored into a dictionary
